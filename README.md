# 🍂 سفر پاییزی ایمنی | افماز

## 🎮 درباره بازی
در این بازی، کاربر در نقش **آرین** — یک دانش‌آموز کنجکاو — قرار می‌گیرد و در ۱۱ موقعیت روزمره تصمیم می‌گیرد. هر انتخاب، یک بازخورد آموزشی و یک نکته علمی به کاربر می‌دهد.
